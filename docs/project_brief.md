## 1. Карточка аналитической задачи

### 1.1. Предметная область и контекст

В рамках работы рассматривается городской сервис проката велосипедов Capital Bikeshare. Датасет содержит почасовые и дневные показатели количества аренд велосипедов за 2011-2012 годы, а также сведения о сезоне, погодных условиях и календарных признаках.

Задача является описательной: необходимо сравнить наблюдаемый спрос на прокат велосипедов в различных условиях. По данным можно выявлять различия и взаимосвязи между показателями, однако нельзя однозначно утверждать, что конкретный фактор является причиной изменения спроса.

### 1.2. Цель анализа

Описать, как количество аренд велосипедов различается в зависимости от сезона, погодных условий и календарных признаков.

### 1.3. Аналитические вопросы

**Основной вопрос.**

Как различается количество аренд велосипедов в зависимости от сезона и погодных условий?

**Уточняющий вопрос 1.**

В какие часы наблюдается наибольший и наименьший спрос на прокат велосипедов?

**Уточняющий вопрос 2.**

Как различается среднее количество аренд в рабочие и выходные дни?

### 1.4. Единица анализа и гранулярность

| Понятие | Описание |
|---|---|
| Единица анализа | Наблюдение о количестве аренд велосипедов |
| Гранулярность исходного почасового файла | Одна строка - один час наблюдения |
| Гранулярность дневного файла | Одна строка - один день наблюдения |
| Основной файл для анализа | `hour.csv` |

### 1.5. Метрики и срезы

| Метрика | Правило расчёта | Единица измерения | Период расчёта | Необходимые поля |
|---|---|---|---|---|
| Среднее число аренд | `avg(cnt)` | Количество аренд | Выбранный срез | `cnt`, календарные и погодные поля |
| Медианное число аренд | `median(cnt)` | Количество аренд | Выбранный срез | `cnt` |
| Максимальное число аренд | `max(cnt)` | Количество аренд | Выбранный срез | `cnt` |
| Минимальное число аренд | `min(cnt)` | Количество аренд | Выбранный срез | `cnt` |

**Срезы для сравнения.**

Сезон, погодная ситуация, час суток, рабочий/выходной день, день недели и год.

## 5. Ограничения и будущие проверки качества

### 5.1. Ограничения набора

- Данные являются историческими наблюдениями за 2011-2012 годы и не описывают текущий спрос на прокат велосипедов.
- Набор содержит агрегированный показатель количества аренд за час, а не информацию о каждой отдельной поездке пользователя.
- Погодные условия представлены кодами категорий и нормализованными числовыми показателями, поэтому для интерпретации необходимо использовать документацию набора.
- Наличие связи между погодой, сезоном и спросом не доказывает причинно-следственную зависимость.
- Данные относятся к конкретной системе Capital Bikeshare, поэтому результаты нельзя автоматически распространять на все города и системы проката велосипедов.
- Показатель `cnt` отражает наблюдаемое количество аренд и не позволяет самостоятельно объяснить причины изменения спроса.

### 5.2. Гипотезы о проверках качества

| Гипотеза о качестве | Как её можно проверить | Почему это важно для задачи |
|---|---|---|
| Количество аренд неотрицательно | Проверить `cnt >= 0` | Отрицательные значения сделали бы показатель спроса некорректным |
| Значения часов находятся в допустимом диапазоне | Проверить `0 <= hr <= 23` | Ошибочные часы исказят временной анализ |
| Значения сезонов находятся в допустимом наборе | Проверить категории `season` | Некорректные коды нарушат сравнение сезонов |
| Значения погодных ситуаций находятся в допустимом наборе | Проверить категории `weathersit` | Ошибочные категории исказят анализ влияния погоды |
| Нет пропусков в ключевых полях | Проверить `dteday`, `hr`, `cnt`, `season`, `weathersit` | Пропуски могут уменьшить объём данных для отдельных срезов |
| Временные значения корректны | Проверить дату и час | Это необходимо для корректного построения временных срезов |
