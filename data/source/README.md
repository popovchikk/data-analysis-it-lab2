# Локальный снимок источника

В эту папку по заданию ЛР №2 помещается неизменяемая копия основного исходного файла проекта:

```text
hour.csv
```

Скачать его можно командой:

```bash
uv run python scripts/download_source.py
```

Файл не обрабатывается и не преобразуется скриптом ingestion. Он хранится только как локальный резервный
снимок источника, а обычный DAG получает данные непосредственно по HTTP.
